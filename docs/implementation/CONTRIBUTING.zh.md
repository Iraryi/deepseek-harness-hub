# 贡献

[English](CONTRIBUTING.md) | 中文

感谢你关注 DeepSeek Harness 并愿意参与贡献！

我们深信开源社区的力量，这份信念从项目最初就塑造着本项目。

DeepSeek Harness 仍处于早期阶段，并在积极开发中。目前我们很遗憾还不能接受外部 Pull Request。不过，贡献代码远不是帮助本仓库的唯一方式，还有许多参与途径：

- 在 GitHub Discussions 中发现并报告问题或 Bug：
  - 为你希望引起团队关注的讨论投票。团队规模很小，可能无法回复每个帖子，但我们会持续关注，并在分配资源时纳入考虑。
- 为生态系统作出贡献：
  - 创建你感兴趣的插件并分享给其他人：
    - 为 GitHub 项目添加 `dsh-plugin` 主题，帮助其他人发现它。
  - 撰写关于 DeepSeek Harness 的博客文章和操作指南。
  - 回答问题并帮助其他社区成员。

DeepSeek Harness 支持深度定制。我们不认为官方仓库中的包天然比社区创建的包更重要。你可以把本仓库视为理念、官方展示和灵感来源，而不是我们要求社区遵循的命令。

我们已经看到社区中出现了令人期待的项目，也希望生态系统继续沿着自己的方向发展。

探索未至之境。
