# DeepSeek Harness HUB `v0.1.0-rc.7` — 2026-08-21

## Update log

- Refresh DSHMK after the cached first paint instead of leaving the HUB permanently labeled `本机缓存` when the live catalog becomes reachable.
- Raise the first-party catalog response limit to 32 MiB and give the official DSHMK endpoint a bounded four-minute transfer window; retain the shorter timeout and coverage guard for alternate raw sources.
- Add live GitHub Stars, repository timestamps, topics, npm version metadata, and a clear `source updated since validation` state to catalog cards and details.
- Distinguish one-click Setup, installation reference, ambiguous installation plans, and local-build-required projects so unsupported projects no longer present a misleading install action.
- Preserve cached-first startup, current filters, pagination, scroll position, and open details while a background refresh completes.
- Keep Full Setup, Lite Setup, Runtime ZIP, Portable ZIP, the PowerShell installer, release manifest, and SHA-256 checksums aligned to the same release version.
