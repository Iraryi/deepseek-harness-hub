# DeepSeek Harness HUB `v0.1.0-rc.7-hotfix.1` — 2026-08-22

## Update log

- Preserve the HUB installed Setup library, manifests, receipts, offline packages, account state, and catalog data during application update and repair.
- Keep portable data identity during the default keep-data uninstall so reinstall selects the same HUB library instead of opening an empty standard data root.
- Recover portable installs created by older uninstallers even when `portable.mode` and the new data marker are both missing.
- Retain one valid `installed.json` backup, recover a damaged primary index, and rebind retained workspaces to the active HUB library path.
- Keep explicit delete-data uninstall destructive: it removes standard data, portable data, and portable identity markers.
- Rebuild the Windows Launcher, Runtime, Full Setup, and Lite Setup with the same `0.1.0-rc.7-hotfix.1` version.

## 更新日志

- 应用更新和修复时保留 HUB 的已安装 Setup 库、清单、收据、离线包、账户状态和目录数据。
- 默认选择“保留用户数据”卸载时保留便携数据身份，重装会继续使用原 HUB 库，不会误进空白的标准数据目录。
- 兼容旧卸载器留下的数据：即使 `portable.mode` 和新数据标记都不存在，也能根据受管理内容恢复便携模式。
- 为 `installed.json` 保留一份有效备份；主索引损坏时自动恢复，并把保留的工作区重新绑定到当前 HUB 库路径。
- 明确选择“删除用户数据”时仍会彻底删除标准数据、便携数据和便携身份标记。
- Windows Launcher、Runtime、Full Setup 与 Lite Setup 统一重建为 `0.1.0-rc.7-hotfix.1`。
