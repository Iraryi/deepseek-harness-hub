## What's changed

- Add HUB management overview, desktop enhancement controls and opt-in LAN phone pairing, device revocation and stop controls. Full includes these features without requiring Overlay.
- Introduce a separate Overlay preview installer for a compatible existing alpha.2 Runtime; keep Full and Lite distributions and all previous releases.
- Embed CONFIG in Settings and HUB while retaining standalone CONFIG. Add unsaved-change prompts, save/restart and optional traffic-light window controls; fix the CONFIG footer and constrained-window layout.
- Add optional bounded background HUB preload after DSH becomes ready, renderer sleep and existing-instance activation. Keep background preload out of the foreground and off the startup critical path.
- Reconcile installed-component inventory with actual Profile declarations, including installations performed outside HUB; preserve ownership information and distinguish declared, present and unverified states.
- Improve catalog freshness/provenance handling, cached-market feedback, sidebar positioning and passive startup focus styling.
- Harden Runtime replacement and configuration retention: bounded retries for occupied files, retained old-Runtime backups and unchanged existing settings during upgrade/repair.
- Correct Full/Lite packaging to include enhancement scripts, mobile assets and catalog resources alongside the matching client bundles.

- 新增 HUB 管理概览、桌面增强设置，以及可主动开启的局域网手机配对、设备撤销和停止连接；Full 内置这些功能，无需另装 Overlay。

## Known issues / 已知问题

- **One-click Setup:** entries such as `zh667/TokenLedger` can display valid install instructions but still disable the install action. This is recorded for the next repair, **not fixed in this release**.
- **一键 SETUP：** `zh667/TokenLedger` 等项目虽然已有有效安装参考，仍可能无法点击安装。已列入下轮修复，**本版本未修复此问题**。
- Overlay is a preview for the qualified alpha.2 Runtime, not universal official Electron Desktop support. Phone access is unencrypted trusted-LAN HTTP with full DSH operator access; no physical-phone or complete installer lifecycle acceptance is claimed.
- Overlay 为已验证 alpha.2 Runtime 的预览适配，不代表兼容任意官方 Electron Desktop。手机连接为未加密、具有完整 DSH 操作权限的可信局域网 HTTP；未宣称完成实体手机或全部安装卸载验收。
- Local targeted tests, built-client checks, isolated runtime activation and package hashes were verified. Repository-wide documentation checks still report inherited upstream-workflow links/catalog issues; these are not presented as passing.
- 已验证本地定向测试、构建客户端、隔离 Runtime 激活及安装包哈希。全仓文档检查仍报告继承的上游工作流链接/目录问题，不宣称全部通过。
