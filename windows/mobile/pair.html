Pair with DSH · 连接 DSH

This phone opens the existing DSH interface on your computer.
手机将打开电脑上现有的 DSH 界面。

HTTP is not encrypted. Use only a trusted private LAN. Pairing gives this device full DSH control, including agent tools and accessible files. Never use public Wi-Fi or internet port forwarding.

HTTP 不加密。仅限受信任的私人局域网；配对后，此设备可完整控制 DSH，包括工具及可访问文件。禁止公共 Wi-Fi 或互联网端口转发。

Links expire in 2 minutes and work once. Device access expires after 8 hours. Revoke or stop access on the computer.
链接两分钟后失效，限用一次。设备权限八小时后失效；可在电脑端撤销或停止连接。
