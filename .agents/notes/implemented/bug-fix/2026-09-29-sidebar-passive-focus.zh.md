# Agent Note: 区分品牌被动聚焦与键盘导航

Status: implemented

[English](2026-09-29-sidebar-passive-focus.md) | 中文

## 问题

用户报告的启动品牌黑圈在交互后消失，因此被动聚焦或选区比静态版本标记背景更值得排查。品牌是侧栏的第一个按钮；单独使用 `:focus-visible` 无法区分宿主分配的启动焦点和主动键盘导航。尚未在隔离原生窗口复现原安装版现象。

## 决策

侧栏局部跟踪文档键盘导航和指针事件，并在卸载时移除监听器。品牌轮廓必须同时满足键盘导航和 `:focus-visible`；被动聚焦保留功能目标而不显示轮廓。品牌子元素禁止文字选择和原生拖拽，品牌控件取消来自扩展图案的拖拽起始事件。该策略不主动移除控件焦点、不清空文档选区、不改变 Tab 顺序，也不阻止其它区域的事件。

## Alternatives considered

移除所有焦点轮廓或禁用整个应用的选择会损害键盘导航和会话复制。强制转移启动焦点会改变用户的活动控件。处理品牌局部问题无须采用这些方式。

## Consequences

键盘 Tab、方向键、Enter 和空格启用品牌焦点提示；指针输入关闭提示。品牌文字不能通过拖选复制。此局部行为修改处理两种疑似机制，但不能证明用户报告的原生启动现象的确切原因。

## 验证

组件测试覆盖被动聚焦、键盘与指针切换、保留激活操作、拖拽取消范围及监听器清理。样式测试约束选择抑制范围和仅键盘轮廓。构建后客户端测试在中英文界面中执行同样的交互。这些检查不能代替受影响安装版的实际确认。
