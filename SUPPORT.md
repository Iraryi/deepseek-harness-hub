# Support

- Use **Bug report** for reproducible HUB, Setup, install, update, restart, or uninstall failures.
- Use **Setup submission** to propose a package or virtual Setup recipe.
- Use **Feature request** for product and ecosystem proposals.
- For upstream DeepSeek Harness behavior unrelated to this desktop distribution, report it to `deepseek-ai/deepseek-harness`.

Always attach the exact release version, Windows version, package ID, installation mode, and the final visible Setup step. Remove API keys and personal data from logs.
