# `@deepseek-ai/dsh-full-capability-pack`

[English](README.md) | 中文

这是面向希望使用完整内置 DSH 组合、而不是极简预设的用户提供的可选内置 Setup 组合包。通过 HUB 安装后，新会话默认选择 `standard` 智能体预设，并在首次使用时启用可持久化的会话全文搜索。

标准预设已经包含当前平台的 Shell 工具、文件系统工具、技能、目标、计划、压缩、子智能体、工作流、任务跟踪和 Web 搜索。本能力包不会启用遥测、保存 API Key，也不会暴露模型隐藏思维过程。

## 模型体验

间接影响，来自为新建会话选择的 `standard` 智能体预设。

#### KV Cache 影响

本包自身不增加模型 Token，也不使缓存失效；具体影响由所选预设挂载的插件负责。

## 已知限制与后续工作

- 已有会话继续使用它们启动时采用的预设。
- 第三方 API 连接器与社区插件仍作为独立、需要审核的 Setup 条目提供。
- 本包不会声称任何模型供应商会公开隐藏思维链内容。
